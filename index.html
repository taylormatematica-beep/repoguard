Rules Engine

8 Strict Architectural Guardrails

Zero config needed. RepoGuard evaluates your entire repository against these battle-tested standards.

RULE-01 Error

No Direct DB in UI

Blocks raw ORM/Prisma/SQL queries inside React components and API controllers. Enforces dedicated service layers.

RULE-02 Critical

Secret Leak Blocker

Catches hardcoded API keys, tokens, and credentials before they get committed to GitHub.

RULE-03 Warning

No Lazy ": any"

Prevents AI models from escaping type safety by throwing : any or as any to pass compilation.

RULE-04 Info

Logger Hygiene

Flags stray console.log calls and enforces centralized, structured production loggers.

RULE-05 Error

SSR Hydration Guard

Prevents Next.js Server Components from calling window or localStorage directly.

RULE-06 Critical

SQL Injection Hazard

Detects dangerous unescaped string interpolations in raw SQL queries and requires parameterized input.

RULE-07 Warning

Unvalidated Payloads

Requires incoming API route payloads to be parsed through Zod schemas before being used.

RULE-08 Info

Anti-Duplicate Utils

Stops AI assistants from re-inventing standard helpers (date formatters, validators) that already exist in /utils.
